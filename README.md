# Camera++ (CameraUniversal)

Camera++ is a lightweight, universal camera application utility built with Python, PyQt6, and OpenCV. It is designed to provide quick access to connected video devices with built-in capture, recording, and filtering capabilities.

## Features
- Hardware Detection: Automatically detects and distinguishes between built-in webcams and external cameras.
- Image & Video Capture: Take high-resolution snapshots or record video (Beta) with custom save directory routing.
- Real-Time Filters: Apply live effects including Grayscale, Sepia, and Invert.
- UI Customization: Selectable stylesheets including Default, Neon Futuristic, and Frutiger Aero.
- Audio-Visual Feedback: Hitmarker overlays and sound effects for UI interaction and media capture.

## Usage
Dependencies: `opencv-python`, `PyQt6`, `PyQt6-Multimedia`, `numpy`

Run from source:
`python camerauniversal.py`

Linux Standalone:
Execute the provided `.AppImage` file directly.
